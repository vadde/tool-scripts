# Architecture Decision Records

> **ADRs capture the reasoning behind key technical decisions.**

## What is an ADR?

An Architecture Decision Record (ADR) documents a significant design decision,
the context that led to it, the options considered, and the consequences.

## Creating a New ADR

1. Copy the template:
   ```bash
   cp docs/architecture/adr-template.md docs/architecture/adr-XXX-title.md
   ```
2. Fill in all sections
3. Submit for review via PR
